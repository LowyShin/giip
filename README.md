## Featured Solution — DPA (Database Performance Analysis)

**Real-time Database Performance Analysis.** Visualize query hotspots, CPU load and bottlenecks in 3D for faster root-cause analysis.

Analyze MySQL, SQL Server and other RDBMS in real time. Agent scripts for Linux/Windows are available, and remote collection as well as serverless databases are supported.
